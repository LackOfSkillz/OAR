# VG00-02: Competitive parity matrix (Outrider Vanguard)

Fetch date: **2026-11-26**. All rows come from each product's public page or listing on that date. Nothing was installed, tested in game, or audited at code level. Capabilities are paraphrased. Where a listing shows a license, it is recorded as shown; no license is inferred. Every entry is a lead for benchmarking, not proof of parity, and nothing here supports a claim that Outrider is first, only or better.

Vanguard areas: **GS** GroupScan (inspection) · **RS** RoleScore · **CQ** CompositionIQ/buffs · **EQ** EncounterIQ · **RO** RaidOptimizer/subgroups · **PC** PrepCheck/supplies · **AC** Access/attunement · **HL** History/logs · **AS** Assignments.

"Forever?" means the page itself says the product is built for WoW Forever (client 1.60.1 / interface 16001).

## Inspect API findings

- **`NotifyInspect(unit)`**: warcraft.wiki.gg documents it for **Forever 1.60.1** with the predicate *AllowedWhenUntainted* (linked to the secret-arguments section). Data arrives with the `INSPECT_READY` event. The target must pass `CanInspect` and `CheckInteractDistance`. The server may throttle requests without firing any event, and `ClearInspectPlayer` ends the session. The page states no combat restriction, so this still needs a probe. [API NotifyInspect](https://warcraft.wiki.gg/wiki/API_NotifyInspect)
- **`GetTalentInfo(tier, column, specGroup, isInspect, inspectUnit)`**: the wiki's version table stops at 1.15.8 Vanilla and lists no Forever range. It also marks the function deprecated since 11.2.0. Whether the inspect form works on Forever is **unconfirmed**. [API GetTalentInfo](https://warcraft.wiki.gg/wiki/API_GetTalentInfo)
- **`C_Traits`, `C_SpecializationInfo`, `GetInspectSpecialization` on Forever**: no public source found. All are now in `Probe.APIS` and read by `Probe:Inspect` (VG00-05).
- **Outrider's own probe (2026-11-25, build 71139):** `GetNumTalentTabs` is **missing** on Forever. Own talents are read through `C_Traits` (Talents.lua). So the Classic talent-tab inspect read in PlayerInfo.lua cannot work; the inspect path must be found by the VG00-05 probe.
- **Indirect evidence that inspected talents are readable**: GearScore Forever (talent trees from inspect, still viewable afterwards), ForeverDB (sequential out-of-combat gear and spec inspect) and NaowhForever (group talents) all advertise it. Their mechanisms are not documented. This is evidence that something works, not which API does it.
- **Restrictions**: secondary sources say Forever follows the same addon restrictions as retail Midnight: no combat log for addons, secret values in combat, and auras on other players hidden. These are summaries of Blizzard statements and community video, not Forever API docs. [Kami-labs, 2026-09-16](https://kami-labs.fr/en/wow-classic/wow-forever-addons-restreints-comme-sur-midnight/); [Blizzard: Midnight combat addon changes](https://worldofwarcraft.blizzard.com/news/24244638); [warcraft.wiki.gg 12.0.0 API notes](https://warcraft.wiki.gg/wiki/Patch_12.0.0/API_changes/notes).
- **Wowhead article 383086** (2026-09-25): body not retrievable. It describes changes to the built-in inspect UI and says nothing verified about addon APIs.

## Raid schedule

**Confirmed by an official Blizzard source.** Blizzard's "World of Warcraft: Forever Raid Overview" ([worldofwarcraft.blizzard.com/news/24303009](https://worldofwarcraft.blizzard.com/news/24303009), published Oct 20; the page shows no year) says Barrow Deeps (10 players), Hyjal Summit (20) and Onyxia's Lair (40) unlock on **December 9**. Raids are "currently planned to reset each week". Onyxia needs the faction-specific Drakefire Amulet in each player's bags; it does not have to be equipped. The article names no attunement for Barrow or Hyjal. Fan and boost sites disagree on Barrow Deeps entrance locations, so use only verified data (hard rule 7). Real raid tests still depend on the actual client unlock.

## Planned reproducible test scenarios

1. **5-player mixed install** (some members run Outrider, some run nothing, one runs a competitor). Compare GearScore Forever (`/gs group`), NaowhForever Group Inspect, ForeverDB group inspect, Singularity Ready leader grid. Measure fields filled, evidence labels (inspected / addon-shared / unknown), scan time, Inspect UI conflicts.
2. **Incomplete inspection** (one member out of range, one in combat, one throttled, the player's own Inspect window open). Compare ForeverDB, GearScore Forever, Raid Prep Check / Forever Raid Ready. Measure false certainty.
3. **Hypothetical subgroup optimization** (20 players, 2 locked, 3 benched, exclusive auras). Compare 1MW, Forevercraft, Azeroth Tools Forever, Second Hearth, WoW Forever Progress, ForeverDB auto-split. Measure coverage spread, explanation quality, rule verification labels.
4. **Encounter access gap** (Onyxia: two members without an amulet, one partway through the chain). Compare Attune, DFL Dungeon Journal, DungeonMaster, Ishkor's Raid Ready, Forever Raid Ready, Prepped. Measure detection and whether the next step is actionable.
5. **Actionable acquisition plan** (a gear or consumable shortfall with a gold limit). Compare Ready for Raid - Forever, Prepped, SimGearForever, Ishkor's, xeR's. Measure cost, runs, prerequisites, uncertainty shown.
6. **Historical outcomes** (several dungeon runs with wipes and success from permitted events only). Compare WowCoach Forever Logs and MRT encounter stats (both combat-log based, so this compares claims, not like-for-like). Measure what Vanguard can learn without the combat log; label everything else unknown.

In every scenario, record evidence coverage, accuracy, actionability, interaction burden and false certainty. A competitor that was not tested scores "unknown", not zero. These are plans; none has been run.
