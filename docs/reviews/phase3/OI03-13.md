# OI03-13: Recovery capability

**Requirement:** on return, resume the pinned plan; revalidate quests that expired, gear, location, time and goals; summarize what changed.

**Acceptance:** an old plan can't be reapplied blindly; the player chooses to resume or start a new plan; long-absence and deleted-quest fixtures pass.

## What was built

`Intelligence/Recovery.lua`, wired into NexusCore.

**At logout**, a small summary of the plan is saved with the planner's settings (`lastPlan`):
- each step's title, quest, item and map
- the pin
- level, gold, map, game build and active goals

A new summary archives the previous one first (`nexusLastPlan`, in the preservation audit).

**At the next fresh login** (not a `/reload`), `Check()` compares the summary with now:

| What | How |
|---|---|
| Quest done since | `C_QuestLog.IsQuestFlaggedCompleted` |
| Quest gone | not completed, not in the log, and absent from its own zone's quest list in the pack (deleted, withdrawn, or not for you now). If that zone isn't loaded it stays unknown, never guessed as gone. |
| Item now worn | `GetInventoryItemID` over the equipment slots |
| Somewhere else, a new level, changed goals, a game update | compared with the summary |
| Long absence (3 days or more) | everything is to look at again, and no step is offered to resume |

**Nothing is reapplied by itself.** The old plan is not restored as current. The Plan page shows a "Welcome back" card listing what changed, with two buttons:
- **Resume where I left off:** pins the first step that's still good and plans again around it.
- **Start a new plan:** drops the pin.

Both buttons have tooltips. Either choice clears the prompt.

## Evidence

- `tests/spec/recovery_spec.lua`, 7 tests:
  - logout saves, login lists a done quest, and nothing is restored
  - a reload gives no prompt
  - Resume pins the first good step; New plan drops the pin
  - a 10-day absence offers nothing to resume
  - a quest missing from its zone's list is gone
  - level, place, goals and build changes are listed
  - a new summary archives the old one, and the card renders with every control tooltipped
- **Found by the tests and fixed:** the first version treated any quest missing from the loaded quest data as gone. Only the quest's own zone report now decides.
- Full suite: Lua 1288 passed, 0 failed. Companion, quality, deps and security gates are all clean.

**Status:** MOCK_GREEN. Live check: with the planner on, log out and log back in the next day; the Plan page shows the welcome-back card.
