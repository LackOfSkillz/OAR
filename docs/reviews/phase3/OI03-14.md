# OI03-14: Benchmark and measurement harness

**Requirement:** repeatable baseline comparisons, paired routes, observed outcomes and held-out estimate metrics; export sanitized evidence.

**Acceptance:** the same fixture gives the same report; sample counts, confidence and unmatched comparisons are disclosed; no causal claim without matching.

## What was built

**`AfterAction.Evidence(input)`** is shipped code. It builds a sanitized summary with no names, character keys or times: counts, medians and map ids only.

| Section | What it holds |
|---|---|
| Quests | Journey's fixed 300 s against the personal estimator (OI03-09), scored on the same later samples (time-ordered 70/30 split), with sample, train and test counts. If there are too few later samples it says "not compared". |
| Routes | walking trips (OI03-05 walking samples only) paired by route (from map to map): trips, median actual, median estimate, and actual ÷ estimate. Routes walked once are counted as unmatched and not compared; flights never enter. |
| Outcomes | counts by kind, and likely versus unknown attribution. It states that "likely" is not proof. |
| Sessions | XP/hour with and without a planner-attributed outcome, compared only within a matched level band and game build with at least 3 sessions on each side. Otherwise "Not compared". A matched difference is called an observation, not proof of cause. |

**Other pieces**
- **`AfterAction.EvidenceText`:** the same summary as Markdown. The After action page has an **Export evidence** button (copy dialog, nothing sent), which has a tooltip and a Help entry.
- **`tests/lib/afteraction_fixture.lua`:** a seeded fixture (quests, trips, outcomes, sessions) using a portable linear congruential generator.
- **`tools/afteraction_bench.lua`:** writes `docs/quality/afteraction_bench.md`.
