# OI03-05: Travel time observations

**Requirement:** record the trips you actually make (with their mode, map, build and interruptions) and keep planned trips apart from actual ones.

**Acceptance:** teleports, disconnects, flights and boats, detours and unknown maps are never mixed with walking samples.

## What was built

`Intelligence/TravelTimes.lua` is driven by the outcome recorder. It uses the same opt-in switch, and trips are saved in `char.outcomes.travel`: the newest 200, with older ones archived as `travelTrips` (in the preservation audit).

**A trip** runs from a destination being set (`OTR_WAYPOINT_SET`: Go, a pin, the waypoint queue) to arriving there (`OTR_WAYPOINT_CLEARED "arrived"`).
- **Planned versus actual:** each trip keeps the planner's own estimate at the start (`Travel:TimeTo`), next to the actual seconds.
- **Abandoned:** a destination replaced before arrival makes the trip "abandoned", kept with no time.
- **No duplicates:** FlightTimes keeps timing flights itself; this doesn't copy it.

**Mode**, the first that applies:

| Mode | When |
|---|---|
| interrupted | a reload, logout or disconnect cut the trip, or you died on the way. An open trip is saved and closed at the next login with how the segment ended. |
| unknown_map | the start or end map wasn't readable |
| teleport | a spell cast followed by a loading screen, or a jump of more than 500 yards, within 15 s |
| flight | a flight path was used |
| transport | a loading screen without a flight or teleport (boat, zeppelin, walk-in portal) |
| ground | none of the above |

**Walking samples** are only arrived ground trips that are not a detour (more than twice the estimate) and had no AFK on the way. Every other trip is kept and labelled, never mixed in.

**Each trip also carries** the play session id and the game build.

  - a replaced destination is abandoned with no time
  - a reload mid-trip is closed as interrupted at the next login
