# OI05-10 macro versioning and rollback; OI05-11 macro regression matrix

## OI05-10: `Intelligence/MacroVersions.lua`

This builds on MacroLibrary's installer, which already refuses combat, full slots, text over 255 characters and macros the player edited.

- **`Preview(entry)`:** the new text, the text the game holds now, a line diff (`+`, `-`, unchanged), length against the limit, validator problems, the rationale (`entry.why`), and the spells the macro casts with their id and rank from the spellbook. It also returns an approval token.
- **`Apply(entry, token)`:** installs only with the token of the current preview. If spells, bags or the macro changed since, the player previews again. It records the rationale and spell fingerprint on the install record.
- **`Stale(entry)`:** after a respec or a new rank (spell id or rank differs), it reports "your spells changed since this was written".
- **`Rollback(entry)`:** restores MacroLibrary's previous text (8 kept, older ones archived). The replaced text goes to the front of the list, so nothing is lost and a second rollback is a redo. It is refused in combat, without history, or over a player's edit.
- **Prohibited:** `/run`, `/script`, `/console` and `/dump` are refused, except MacroLibrary's own quiet line. Nothing is ever pressed by Outrider.

## OI05-11: `macroversions_spec` regression matrix

For each of the 9 classes, every class and general pack macro is filled with fixture values and checked against:
- 255 characters or fewer, and no validator errors
- no script commands
- no `,null` castsequence (it doesn't hold on Forever, measured 2026-11-21)
- rank-less `/cast` (C13)
- modifiers only shift, alt or ctrl
- reset values only combat, target, a modifier or seconds
- no empty sequence steps
- none of the spells removed on Forever

**Limits:** these tests check generated text and known restrictions only. They do not show that a key sequence gives a combat result; that stays with the owner's in-game fight logs. Status: MOCK_GREEN.
