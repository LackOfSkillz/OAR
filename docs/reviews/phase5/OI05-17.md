# OI05-17: Oracle and Forge UX (`Intelligence/OraclePage.lua`)

A **What if?** section on the Gear page, registered through `Hub:AddSection("gear", { key = "whatif", ... })` and drawn by the Gear page through `Nearby.Section(key)`.

- **Your damage estimate:** the Forge's range for a one-minute fight from your own tooltips. The plain line comes first, then why it's a range, what's partial and what isn't modelled. *Copy details* exports it.
- **Try an upgrade:**
  - *Save now* takes a frozen copy of you.
  - *Try top upgrade* puts GearROI's top pick (and its price, when it's known and affordable) on that copy, and the Oracle compares the two. The plain line shows the trade-offs; the detail shows each known difference and what can't be told.
  - When you changed since saving, the card says so and offers *Refresh*.
  - *Reset* forgets the copies.
- **No live mutation:** these buttons only change in-memory copies; the live character's hash is unchanged (tested). Every button has a tooltip. A Help entry was added and USER_GUIDE rebuilt.

**Fix found while doing this (Phase 4 regression):** `UI/Hub.lua` defined `Hub:AddSection` twice. The old pre-tab alias `(title, build)` came later and replaced the OI04-GATE registry, so GearROI's "Worth getting?" never reached the Gear page. It is now one definition handling both shapes, and the sections are looked up by key. Covered by `oraclepage_spec`.
