# OI02-14 Cross-language contract tests

Date 2026-11-24.

- **Lua to Python:** `tools/nexus_fixtures.lua` exports every valid shared fixture through the addon's own OTR1 transport (`Serialize.Export`) into `tests/fixtures/contract/nexus_v4_otr1.txt`. The Lua spec checks the committed file is exactly today's export. The Python test decodes each code with the companion's `codes.import_code`, gets the identical record back (ids, numbers, lists), and the v4 validator accepts it.
- **Python to Lua:** `nexus_v4_otr1_py.txt` holds codes made by the companion's encoder. The Lua spec decodes them to identical, valid records, and the Python test checks the file is current.
- **Float formatting:** the two encoders write a float such as 0.6 differently (Lua `%.17g`, Python `repr`), but both decode to the same value, so equality is checked on decoded values, not bytes.
- **Fuzzing:** 900 seeded mutations on each side (bad values, removed fields, extra keys such as action/macro/run/script/cast). More than 500 are rejected. Any that still validate carry no extra key and no intent outside waypoint, panel or none.
- **Execution boundary:** a decoded record with no producer candidate behind it cannot act (`Act` refuses).
- Legacy v1-v3 transports are unchanged and still pass `contract_spec` and `test_contract_golden`.

Tests: `nexus_transport_spec` (4) and `test_nexus_transport.py` (3). Full suite 1128 passed, 0 failed; companion and gates clean.
