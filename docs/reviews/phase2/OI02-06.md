# OI02-06 Candidate adapters: progression

Date 2026-11-24. New `Intelligence/Adapters.lua` (`ns.NexusAdapters`). It reads WhatNow's existing producers, which are the source of truth:

- errands: Errands, Nearest
- quests: Journey's quest XP list over QuestInfo and NPCPack data
- dungeons: DungeonGuide, Travel
- dungeonquests: DungeonQuests
- plus the current LevelRoutes step

Each suggestion becomes a v4 Opportunity:
- deterministic id `opp:<source>:<key>` and `legacyCandidateId`;
- label to confidence, the producer's confidence to risk, seconds to costSeconds;
- intent is waypoint, panel or none; the producer's `go()` stays runtime-only and runs only on the player's click.

Missing or bad data is excluded with a reason: no key, no title, no benefit, not an opportunity (tips), invalid field, secret. A failing producer is reported as unavailable while the others carry on. The same quest from two producers (questID, `quest:`, `dq:`) is one opportunity: the better benefit wins and the other is listed as a duplicate.

Nearby (gear) is a resource producer and is mapped in OI02-07.

Tests: `nexus_adapters_spec` (5): deterministic ids and valid records, exclusions with reasons and a failing producer, quest de-duplication, the level-route step, real producers end to end. Full suite green.
