# OI02-08 Dependency graph

Date 2026-11-24. New `Intelligence/Graph.lua` (`ns.NexusGraph.Build(opps, meta, ctx)`). It draws prerequisite, mutually exclusive, overlap and travel edges, and returns a deterministic prerequisites-first order (Kahn, ties broken by id).

- A node becomes invalid, with its reason, on a faction mismatch, an unmet prerequisite (unless done), a cycle (every node in the loop), needing an invalid node, or a cost above the spendable gold (gold minus reserve). Nothing is dropped quietly.
- Overlapping rewards count once: the best node keeps its benefit, the others get `countedBenefit = 0` with a note.
- A different map without a travel estimate is `travelUnknown`: unknown, not zero.
- `ResourceConflicts` lists pairs that together exceed the spendable gold.

Tests: `nexus_graph_spec` (5): prerequisite order and unmet or done prerequisites; a cycle spreading to dependants; faction, budget and travel unknown versus known; overlap, exclusion and resource conflict; determinism. Full suite green.
