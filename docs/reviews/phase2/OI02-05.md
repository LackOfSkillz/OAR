# OI02-05 Goal model

Date 2026-11-24. New `Intelligence/Goals.lua` (`ns.NexusGoals`): several goals at once as v4 Goal records (level, gold, gear, professions, explore, mix), priority 1-5, optional target, deadline and gold reserve. Character goals in `char.nexusGoals`, account goals in `global.nexusGoals`.

- Create, Edit, Pause, Resume, Complete. Delete sets status `archived`; nothing is removed (data preservation override).
- Edits are validated as a whole; a failing edit changes nothing and names the field.
- `Active()` sorts by priority, then age. With no goals, WhatNow's single goal stands in, marked implicit.
- `Check(now, state)` explains problems with a code and a sentence, and changes nothing: deadline passed, target above the level cap, already reached, gold reserve above carried gold, duplicate aim, priority tie.

Tests: `nexus_goals_spec` (4): CRUD persistence per scope across reload and another character, refusals with the field, ordering and the WhatNow fallback, every problem code with goals left untouched. Full suite green.
