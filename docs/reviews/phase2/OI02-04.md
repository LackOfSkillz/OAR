# OI02-04 Character and account state

Date 2026-11-24. New `Intelligence/State.lua` (`ns.NexusState`): a read-only view over gold, level, location, gear (item ids by slot), spellbook (count), inventory (bag totals) and professions (the Professions module's public Snapshot), plus alts from their saved snapshots.

- Fields are read lazily through public functions and the client. Each is cached with its read time and revision, and dropped only by the events that can change it (PLAYER_MONEY: gold; PLAYER_EQUIPMENT_CHANGED: gear; BAG_UPDATE_DELAYED: inventory; ...).
- Alts are always `live = false` with `ageSeconds` and a plain age line; an alt's gold or level is never shown as current.
- No writes to saved data, and no private module fields: the deps gate reports 0 new.

Tests: `nexus_state_spec` (4): per-field invalidation (a bag update keeps gold and location; the money event refreshes only gold), unknown and failing fields reported, alts not live with age, no saved-data writes. Full suite 1078 passed, 0 failed; gates clean.
