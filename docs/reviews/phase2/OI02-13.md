# OI02-13 Confidence and Troubleshooter core

Date 2026-11-24.

- `NexusCore:Diagnose()` returns `{ kind, code, text, remedy }`. There are three kinds:
  - **error:** a source of suggestions couldn't be read; if every source failed it says so as a fault;
  - **limit:** a real constraint, such as over budget, unknown gold, other faction, a missing or blocked prerequisite, a prerequisite cycle, or a goal problem;
  - **info:** context, such as the planner being off, no plan yet, a stale plan, or how many steps rest on guesses.
- Rejected steps are grouped by reason code with a count. The planner now gives a code with every missing plan: `no_candidates`, `over_gold`, `over_time_or_gold` or `invalid_plan`. A missing plan caused by read failures is marked as an error, so a fault is never shown as "nothing to do".
- Texts carry no character names, realms or exact gold amounts.
- The Plan page has a "What's holding the plan back" section: errors in red, limits in amber, info in grey, each with its remedy.

Tests: `nexus_troubleshoot_spec` (4): codes and text for a rejected step and a missing plan; error versus nothing to do; stale plans, uncertain estimates, goal problems and no private details; the page builds. Full suite green.
