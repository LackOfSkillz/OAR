# OI02-02 Evidence registry

Date 2026-11-24. Extends `Intelligence/Evidence.lua` (no new service):

- Sources declare `sourceType` (module, pack, player, client) and `canVerify`. "verified" is refused from any source not registered with canVerify, whatever its name.
- Facts carry provenance (source, sourceType), the observing character, the addon build, privacy (`local` by default), confidence label, revision and per-kind TTL (existing table).
- `Get` refuses with a reason: missing, stale, future (observed more than 5 s ahead), other character, other build. `AsV4` returns a validated v4 Evidence record.
- Secret keys and values never enter (existing `plain` filter, now tested).
- Ruleset: Forever has one ruleset per client here; the build check covers client changes. A ruleset field can be added in a later schema version if realms differ.

Tests: `nexus_evidence_spec` (5): malformed input, verified-by-name refusal, stale/future/other-character/other-build reasons, secrets, v4 record. Existing `intelligence2_spec` evidence tests pass unchanged. Full suite 1068 passed, 0 failed; companion, quality, deps, security clean.
