# OI04-14: Dungeon decision improvements

**Requirement:** rank eligible dungeons by gear, XP, quest prerequisites, reputation, readiness and realistic group constraints.

**Acceptance:** no assumption of guaranteed drops or group availability; the existing dungeon quest and readiness UI stays intact.

## What was built

`Intelligence/DungeonDecision.lua`. It covers the dungeons that fit your level (`DungeonQuests.Fit`), and it reads only; nothing in the existing modules changed.

| Factor | Source | How it's shown |
|---|---|---|
| quests (XP) | dungeon quests still to do (DungeonQuests status) | "N quests to do (pick up N before you go)" |
| gear | DungeonGuide's upgrade count and value | "N possible upgrades: possible, not guaranteed" |
| readiness | your level within its range | "levels X-Y, you are Z" |
| group | the Horizon solo choice | solo: ranked last with "you chose a solo session"; always "needs a group: whether you'll find one is unknown" |
| reputation | none for dungeons yet | "reputation: no data", not guessed |

**Score:** 0.4 × quests + 0.4 × gear + 0.2 × readiness, each from 0 to 1.

**Display:** the Dungeons page gets a "Which dungeon, and why" section at the top (top 3). Its existing rows, and the Dungeon quests page, are unchanged.

## Evidence

  - solo puts dungeons last
  - both pages build, with the existing rows kept
