# OI01-08 UI Pages decomposition

Date 2026-11-24. `UI/Pages.lua` (1822 lines) is now split into `UI/Pages/`:

| File | Pages |
|---|---|
| Kit.lua | shared helpers `mod`, `set`, `onoff`; `ns.PageKit` (also carries `classTalentPoints`) |
| Home.lua | home |
| World.lua | waypoints, rarealerts |
| Character.lua | class, gearsets |
| Gold.lua | profdetails, money, dungeons |
| WhatNow.lua | whatnow |
| Social.lua | chat, sharing (and `ns.ShowDiscord`) |
| Settings.lua | settings, commands |

The code moved as whole line ranges. The only change is each file's header (the same locals as
before), and one shared function (`classTalentPoints`, Home to Character) now passes through
`ns.PageKit`. The other apparent cross-file name matches were words inside strings.

## Evidence

- Same page ids, titles and sidebar order: a script loads the addon in the mock and prints every
  `ns.Hub.tabs` id, title and order. Before (HEAD `d4bcaa7`) and after are byte-identical
  (`cmp` passed).
- Suite: `tools/test.ps1 -RequirePython`: 1011 passed, 0 failed, companion passed. The hub,
  tips (every control has a tooltip), stat strip and boot (every TOC file loads, every command runs)
  specs cover all moved pages.
- TOC: `UI\Pages.lua` is replaced in place by the eight files, in the original order.
- Quality baseline: Pages.lua's three long functions now sit in Home.lua and WhatNow.lua. They are
  the same functions under new paths, so `docs/quality/baseline.json` was re-recorded: 22 findings,
  one fewer than before because the file-size finding for Pages.lua is gone.
- Deployed build 20261124-080127. The deploy removed the old Pages.lua from the game folder. A full
  restart is needed (the file list changed).
