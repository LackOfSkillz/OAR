# OI01-11 Error and event semantics

Date 2026-11-24.

## Fixes

1. **Failed event registration was recorded as success.** `Core/Events.lua` kept a handler list and
   returned a handle even when `RegisterEvent` threw, so callers believed the feature was on. Now:
   - the event is marked unavailable for the session;
   - `Events:On` returns `nil, "unavailable"`, and `Module:On` passes that through;
   - no handler is kept (`Count` is 0);
   - later calls return at once without trying again, so there is no retry storm;
   - one log line is written, as before.
2. **Module-owned timers.** `Module:After` and `Module:Ticker` (Core/Modules.lua) record their
   handles, and `Modules:Disable` cancels any still pending, along with the events, as before.
   Fired one-shot timers are forgotten, so nothing leaks.
3. **Tickers left running after disable:**
   - LagCheck had no OnDisable, so a running check kept sampling after the module was switched off.
     It now stops.
   - FishingRing's lure-flyout ticker is now cancelled in OnDisable.

## Audit

Modules with `ns.Timer.Ticker`: Coords, FishingHUD, FishingRing, LagCheck, LocationShare,
MinimapPins, Nearest, NetTest, Path, Trail, Waypoints, SessionXP. Every one now cancels its ticker
on disable, directly or through its Stop or Clear function (LocationShare, NetTest and Waypoints
already did that through Stop/Clear). `ns.Safe` wraps every handler and timer run, and failures go
to Core/Errors (unchanged). `Talents.lua` defines its own `M.After(build)`; it shadows the new
method on that one module only and doesn't use module timers, so nothing changes there.

## Tests

`tests/spec/eventsemantics_spec.lua` (5 cases):
- a refused event returns unavailable, keeps no handler and is registered only once;
- Module:On passes "unavailable" through;
- a registrable event still returns a handle;
- disabling cancels both owned timers and all events;
- a fired After leaves no entry;
- LagCheck stops mid-check when switched off.

Full suite: 1016 passed, 0 failed; companion passed; quality 0 new.
