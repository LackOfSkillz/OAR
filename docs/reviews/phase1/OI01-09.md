# OI01-09 MacroTree decomposition

Date 2026-11-24. `Modules/MacroTree.lua` (1204 lines) is now three files, loaded in this order:

| File | Holds |
|---|---|
| MacroTree.lua (167 lines) | module, lifecycle, action-bar tooltips, new-unlock notice |
| MacroTreeModel.lua | eligibility (level band, talent tree, spells), keys and items, grid model, state, old-build audit, pick-up, explanations |
| MacroTreePage.lua | column widths, slot buttons, the Macros page rendering |

Each piece moved as a contiguous line range with a header that names the same locals (`C`, `E`, `UI`, `T`).
A cross-reference scan found no other file-level locals shared between the parts. No secure or
protected call was added or changed: pick-up still runs only from the player's drag, out of combat.

## Remaining

the closure shares about 40 upvalues, and changing it would need an in-game visual check. It stays
in the quality baseline.
