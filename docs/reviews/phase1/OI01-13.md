# OI01-13 Security checks upgrade

Date 2026-11-24. New gate: `tools/security_check.py` (standard library), run by `tools/test.ps1`
(local and CI) as a `--selftest` plus a full-repo check. It adds to the existing regex tests in
`companion/tests/test_security.py`; those still run.

## What it checks

- **Lua, by token** (comments ignored, string literals included):
  - banned names: text execution (loadstring, RunScript, RunMacroText, load), protected or automating
    actions (CastSpellBy*, TargetUnit, UseAction, SendChatMessage, quest accept and complete, auction
    bid and post, merchant buy, movement), and the combat log;
  - looking a banned function up by name (`rawget(_G, "SendChatMessage")`) is caught too;
  - allowed uses are listed per file with the reason.
- **Python, by AST:** eval, exec and compile, os.system, shell=True, pickle and marshal; network
  imports outside the listed network files; URL hosts outside the allowlist (the three model
  providers the owner configures, localhost, wago.tools, GitHub, CurseForge).
- **Secrets** in every tracked text file: sk-, AKIA, ghp_, xox and quoted api_key/token values.
  Placeholders are skipped.

## Findings and what changed

1. **FishBook Share (added 2026-11-24, earlier in this session) bypassed the old check.** It
   reached `SendChatMessage` by name to post to guild chat. Fixed: Share now opens a copy box with
   the line, and Outrider sends nothing. The spec, help text and changelog are updated.
2. **PartyQuests** sends quest progress lines to PARTY chat (setting `announce`, on by default,
   rate-limited queue, turns itself off when Questie announces). It is an existing reviewed feature
   and is allowlisted with that reason. **Owner note:** these lines go out on quest events, not on a
   click. Blizzard allows PARTY chat from addons (Questie does the same). Listed for the gate in case
   Gary wants it off by default.
3. **Merchant restock** (`BuyMerchantItem`): called only from the visible Restock button with the
   vendor open and out of combat. Allowlisted with that reason.
4. `tools/import_crafting.py` downloads wago.tools client tables (fetched with Gary's OK). It is
   added to the network-file list.

## Negative fixtures (selftest)

The selftest plants each banned Lua pattern (incl. a name in a string and in `_G["..."]`, with a
comment that must not count), each banned Python pattern, an off-list URL, and a secret built at
runtime (so the repo never holds one). Every planted problem must be reported.

## Limits

Static only: a name built at runtime from pieces would pass. That is listed in the review checklist.

## Result

Full suite: 1016 passed, 0 failed; companion passed (incl. the old security tests); quality 0 new;
deps 0 new; security 0 violations across 223 Lua, 59 Python and 614 text files.
