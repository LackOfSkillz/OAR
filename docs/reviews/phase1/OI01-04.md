# OI01-04 Runtime and UX baseline

Date 2026-11-24. Status: **LIVE_PENDING**. The capture is built and mock-tested. No real-client
measurement exists yet, and no mock number stands in for one.

## What is captured (self-collecting, CLAUDE.md section 3.5)

At every logout (and /reload), `Modules/AutoCheck.lua` calls `ns.Perf:Report(true)`. It now saves a
row per session to `Outrider_DB.global.perfRuns` (last 10 sessions) and writes one log line:

| Field | Source | Notes |
|---|---|---|
| memoryKB / memoryRawKB | `GetAddOnMemoryUsage` after and before one full GC | existing |
| handlers, events, timers, timer driver, combat queue | Core/Events, Core/Timer, Core/Combat | existing |
| modulesOn, secureButtons | Core/Modules, UI/SecureButtons | existing |
| runtime.client | `GetBuildInfo` version and build | new |
| runtime.boot.initMs | ms inside our ADDON_LOADED step (DB, log, module init) | new, `debugprofilestop` |
| runtime.boot.loginMs | ms inside our PLAYER_LOGIN step (UI, modules enabled) | new |
| runtime.frames | count of named `Outrider_` frames | new; unnamed frames aren't counted (no cheap API) |
| runtime.cpuMs | `GetAddOnCPUUsage`, only when the player already has `scriptProfile` on | new; Outrider never turns profiling on. Otherwise recorded as `unavailable: scriptProfile is off` |
| runtime.errors / taint | this session's entries in Core/Errors | new |

Per-frame average (ms/frame) is not captured: it needs `scriptProfile`, which costs every addon
CPU time. It stays unavailable unless Gary chooses to enable it.

## Live protocol (Gary: plain game actions, no slash commands)

1. Exit WoW fully, start it, log in on Torrant.
2. Play normally for at least 10 minutes. Open the Outrider window once, then open the auction house,
   a vendor and the world map once each (common workflows).
3. Log out.
4. Repeat on the priest and the mage if convenient.

Claude reads the result with `tools/read-logs.ps1` (lines `perf runtime:`, `perf mem`). It then copies
the sanitized numbers, without character names or gold, into this file with date, client build and
Outrider build.

## Tests

`tests/spec/perf_spec.lua`, the new case "logout records a runtime baseline row": checks the client
build fields, both boot timings, the frame count, the CPU-unavailable path, the error count,
per-session overwrite and the 10-row cap.
