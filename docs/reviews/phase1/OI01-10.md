# OI01-10 GearShop decomposition

Date 2026-11-24. `Modules/GearShop.lua` (965 lines) is now three files, loaded in this order:

| File | Holds |
|---|---|
| GearShop.lua | module definition, item kinds, auction query sequence (Queries, Start, Next, OnResults, Done), lifecycle |
| GearShopRank.lua | ranking: fits the class and armor, bag and quiver upgrades, results, overall gain, provider, icons |
| GearShopView.lua | cards, cart state, card click, the confirmation path (BuyAll and Pick), window build, refresh |

Contiguous line ranges moved with identical code. The shared locals (`C`, `UI`, `M`) are declared in
each header. No background purchase or scan was added: buying still needs the player's
confirm click, as before.

  (1011 passed, 0 failed; companion passed; quality 0 new).
