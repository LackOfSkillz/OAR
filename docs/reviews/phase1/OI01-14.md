# OI01-14 Migration and recovery foundation

Date 2026-11-24. This task also carries out the owner's retention decision (option 3) under the
[data preservation override](../../blueprint/OWNER_DIRECTIVE_DATA_PRESERVATION.md).

## Archive instead of delete (new)

`Core/Archive.lua` (`ns.Archive`) holds rows that leave a capped working store. Rows are kept
unchanged in `Outrider_DB.global.archive["<key>@<character>"]`, oldest first. 27 places that used to
throw collected data away now move it there:

| Data | Archive key |
|---|---|
| auction daily lows past 14 days | prices |
| price history rows past 120 days or 720 rows; untracked items' whole history | priceHistory, priceHistoryItems |
| rare sightings and observations | sightings, sightingObservations |
| spawn log | spawnLog |
| walked trail | trail |
| quest diary | questDiary |
| fights | fights |
| fishing sessions and notable catches | fishSessions, fishNotable |
| gold ledger, sales ledger, auction posts, economy outcomes | goldLedger, salesLedger, auctionPosts, economyOutcomes |
| XP sessions | xpSessions |
| deaths | deaths |
| layer history | layerHistory |
| herb and ore node states | nodeState |
| pets seen | petsSeen |
| rare cast gaps | rareCastGaps |
| recent discoveries | discoveredRecent |
| chat archive (only when the player turned it on) | chat, chatByPerson |
| feedback reports, advisor feedback | feedback, adviceFeedback |

**Kept as caps** (logs and debug, per the decision): event log, error list, boot session list,
perf runs, probe units, slow-handler list, combat queue, send queues, undo stacks, top-N display
lists.

**Not changed:** deletions the player starts on purpose (Undo/Erase on a route, removing a wanted
fish, `/ride reset`). They are the player's own choice, not automatic deletion. Expiring
lockouts and other stale state that gets replaced by newer data are allowed by the decision
("outdated data may be replaced by newer or better data").

The working stores keep their sizes, so pages and lookups stay fast. Only the archive grows. Its row
count can be added to the perf report (`ns.Archive:Count()`), which shows how fast the saved data
grows on Gary's account.

## Migration and recovery coverage (existing plus new)

- `db_spec`: damaged SavedVariables survive; characters stay separate; settings survive
  logout and reload.
- `safety_spec`: a file from a newer Outrider is left untouched (safe mode); a failing migration
  step doesn't damage the original; a missing step is refused, not skipped; a working migration
  upgrades and saves; reset rebinds immediately; reset-all writes nothing back.
- `archive_spec` (new, 6 cases):
  - put, shift and rows;
  - a damaged archive (bad types) loses no new rows;
  - prices past 14 days are archived;
  - price history past its cap or age, and untracked items, are archived whole;
  - sightings are archived;
  - logs keep their caps.
- Feature disable: covered in OI01-11 (events and owned timers removed on disable).
